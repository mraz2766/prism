# 网络测试与 WebRTC 检测实施计划

## 范围与决定

- Swift / SwiftUI 原生网络测试页，入口位于详情窗口与菜单栏弹窗。
- 国内参考使用 `https://www.baidu.com/favicon.ico`；海外使用 Google 204，以及 Gemini 与 ChatGPT 的 `/robots.txt`。
- 只测响应耗时（统一以秒显示，保留三位小数）、成功率和延迟波动，不执行带宽测速，不下载完整响应正文。
- 每站点 3 次采样，最多 2 个同时请求。每次使用独立临时会话，统一测新连接收到响应头的耗时（系统 DNS 缓存仍可能复用）；不将冷、热连接混合统计。
- 默认跟随系统网络与代理规则；国内站点不被宣称为必然直连。不控制代理、不扫描个人配置端口。
- WebRTC 使用系统 WebKit 的真实 RTCPeerConnection，仅创建数据通道进行 ICE 收集。Swift 负责生命周期、候选解析和比较，内嵌最小 JavaScript 调用浏览器 API。不申请摄像头或麦克风，不载入远程检测网页。
- 手动测试时联系 Cloudflare 与 Google STUN，候选只保存在本次内存。WebKit 与用户其他浏览器的策略可能不同；无公网候选、超时、不支持均不等于“无泄漏”。仅在同地址族的当前 HTTP 出口可用时比较，差异报告为可能存在不同网络路径。
- 作为独立的附加诊断能力，不改变已有出口监控架构，本批按小改动发布一次。

## 视觉与交互

- 视觉主旨：沿用 Prism 的原生安静表面，以大号秒数、单一强调色和真实数据曲线建立层级。
- 内容：标题与操作、WebRTC 单行结论 → 所选站点延迟和曲线 → 四个站点采样详情（判断范围仅保留悬停提示）。
- 动效：采样完成推动环形进度；数字与折线平滑更新；站点活动状态呼吸、详情展开过渡。遵循减少动态效果，完成后停止循环动画。
- 不生成虚构采样，不把不同站点的耗时平均成代理质量分数；失败采样在曲线上留空。

## 实施步骤

1. 新建类型、统计与 HTTP 探测服务，区分请求错误、HTTP 受限与正常响应。
2. 实现可取消的 WebKit ICE 检测、候选去重与保守地址分类。
3. 实现 ViewModel：进度流、重复启动隔离、网络/出口变化失效、停止与重测。
4. 集成 SwiftUI 页面、导航、弹窗入口、中英文本与 README 服务说明。
5. 测试统计、错误状态、候选分类、比较边界、取消与失效；通过 UI 测试检查页面和动画状态。
6. 执行 `./scripts/release.sh small`，仅验证通过后安装 `/Applications/Prism.app`，本地中文提交，不 push。

## 验收要点

- 默认不发起测试；开始后有明确的逐项进度，停止后旧任务不能回写。
- 12 次请求耗时采用一致口径；HTTP 403 有耗时但不计入成功样本，展示访问受限。
- 网路/代理变化或休眠导致当前结果失效；已完成结果保留时间并标记旧结果。
- WebRTC 只显示出口一致、出口不一致或暂无法判断等单行结论；mDNS、私网、无结果不做安全保证；IPv4/IPv6 分别比较。
- 测试失败不得影响原有出口状态，也不得触发出口历史或通知。

### 用户反馈后的收敛

- Gemini 和 ChatGPT 的旧 `/favicon.ico` 均实际返回 404，已逐站用一次原生 URLSession 请求验证 `/robots.txt` 返回 200；收到响应头即取消正文读取。
- 将 404 单独表述为“测试路径不存在”，403 / 429 表述为“网站限制访问”，不暗示代理连接失败。
- WebRTC 收敛为单行：左侧名称，右侧状态图标与结论。一致为绿色，不一致为提示色，结果不足为中性色；不再显示候选 IP、HTTP IP、协议和多行解释。检测限制仅保留在默认折叠的测试说明中。
- 保持每站点 3 次、总计 12 次采样，未改动其他页面或原出口识别逻辑。
- 收敛版本发布验证：全量 235 项单元测试，234 项通过、1 项显式联网测试默认跳过，Release 构建与签名安装通过；两个新端点已各用一次真实请求确认 HTTP 200。
- 安装版原生 UI 已确认 WebRTC 只保留名称与单行状态，测试说明默认折叠；此次检查未额外启动整轮网络测试。

### 国内目标与官方图标调整

- 按用户最新决定，将国内目标更换为百度，不采用阿里云。原生 URLSession 单次确认 `https://www.baidu.com/favicon.ico` 返回 HTTP 200。仍跟随系统网络路径，不据站点位置宣称直连。
- Google 当前 `https://www.google.com/generate_204` 单次确认返回 HTTP 204，无重定向，保留该空响应探测端点。
- 四个站点均使用官网发布的图标；Gemini、ChatGPT 图标地址从官网 HTML 的 icon 链接读取。图标预处理并随应用打包，测试时不下载图片。
- 图标保持原有颜色和形状，活动状态使用旁侧的小圆点，保留每站点 3 次采样和单行 WebRTC 结论。
- 本批全量 235 项单元测试：234 项通过、1 项联网测试默认跳过；Release 构建、签名校验及安装通过。已在正常安装版窗口目视确认百度、Google、Gemini、OpenAI 四个图标正确显示，未启动额外整轮测速。
